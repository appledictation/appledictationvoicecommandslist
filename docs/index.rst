What Are Apple Dictation Voice Commands?
========================================

Apple Dictation voice commands are spoken instructions that allow users to control text input while dictating. Instead of manually pressing keyboard keys for punctuation or formatting, users can simply speak commands aloud.

For example, saying "comma" inserts a comma, while saying "new paragraph" creates a new paragraph automatically.

These commands make Apple Dictation more powerful by allowing users to write naturally while maintaining control over document structure.

Apple Dictation vs Voice Control Commands
=========================================

Many users confuse Apple Dictation with Voice Control.

Apple Dictation focuses mainly on converting speech into text.

Voice Control provides broader device control, including:

* Opening applications
* Clicking buttons
* Navigating menus
* Editing documents
* Controlling the entire interface

Users who need complete hands-free operation may benefit from Voice Control instead of standard Dictation.

Common Apple Dictation Command Problems
========================================

Some users experience issues where commands are typed as normal words instead of performing actions.

Common causes include:

* Unsupported commands
* Incorrect language settings
* Poor microphone quality
* Background noise
* Outdated software
* Application limitations

Testing Dictation in another application can help identify whether the problem is system-related or app-specific.
